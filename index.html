One prompt. One attempt. No fixes.

Each model gets the same brief and a single shot at building a working Klondike Solitaire PWA — no follow-ups, no fixes. The results are published as-is so they can be compared across rounds and across the gap between frontier and locally run models.

The prompt

Given verbatim to every model. Nothing else — no spec, no follow-up.

I want to build a classic Solitaire game as PWA app for a phone. Take a good existing spec for a game, nothing fancy. Main thing it should be fully working with one shot attempt to build it. Take your time to carefully design it and use standard development process so you can get to final result with no hiccups or flops in the middle.
