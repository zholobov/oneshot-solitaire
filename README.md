# One-shot Solitaire

Index page for a recurring benchmark: the same Solitaire-PWA prompt given to frontier and local
models, one attempt each, results published as generated. Re-run every six months to track progress.

Live: https://zholobov.github.io/oneshot-solitaire/

Each round is a section in `index.html`; add a new section above the previous one when a new round is run.

Per-model repositories: `oneshot-solitaire-<model>`.
